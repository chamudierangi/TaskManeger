#  TaskManager Android App<img width="1152" height="642" alt="demo" src="https://github.com/user-attachments/assets/22f4c7dc-f472-4aa4-b6ea-85879d2b9992" />


A simple and efficient Task Management application built with **Java** and **Firebase**. This app allows users to register and manage their daily tasks with real-time data synchronization.

---

##  Features
* **User Authentication:** Simple sign-up process with Name, Email, and Password.
* **Real-time Database:** Powered by **Firebase Realtime Database** for instant data saving.
* **Personalized Experience:** Displays a warm welcome message with the user's name on the home screen.
* **Clean UI:** Minimalist and user-friendly design with custom backgrounds.

##  Technologies Used
* **Language:** Java
* **IDE:** Android Studio
* **Backend:** Firebase (Realtime Database)
* **Version Control:** Git & GitHub
